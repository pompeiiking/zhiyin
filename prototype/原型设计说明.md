## 0. 本次重构（核心交互逻辑）

上一版原型把「建档」做成了**上传表单 + 四步向导**，违背了 [职引-BRD.md](../职引-BRD.md)（§六 / §七）定义的「进入对话 → AI 分步提问采集画像」。本版重构为**对话式**，两条原则：

1. **表单是对话的产出物，不是前置输入**：AI 一次只问一个关键缺口，右侧「个人画像」抽屉随对话逐步被填充（0/6 → 6/6），用户全程不填表。
2. **成熟方法论显式锚定为骨架**：每个画像维度、每条 AI 提问、每个解析/方案/行动分段，都标注支撑模型（见 [§5.2 方法论对位表](#52-方法论对位表)），方法论从「附录对照表」变为「交互骨架」逐处可见。

早期「上传表单 + 四步向导」版本仅作为演进记录，不纳入当前交付物清单；当前可运行交付物为 `index.html`。

## 1. 设计来源与风格基线

原型延续 TipoMRI 的**前端视觉语言**，交互范式对齐求职精灵 GenieLink 的**对话式建档 + 画像沉淀**。视觉令牌通过浏览器实测从 mri.tiposhot.com 提取，落到职引语境后按「职业规划」语义做了领域化扩展：

1. **双强调色体系**沿用：蓝 = 主行动/权威（解析、生成、导出），绿 = 完成/成长（画像沉淀、任务勾选、阶段完成）；
2. **分类淡底色模式**沿用 mri 各类目卡的淡色底（蓝/绿/红/紫/琥珀软色），用于职业工作台矩阵区分场景。

### 1.1 令牌对照表（参考站 → 职引原型）

| 设计令牌 | TipoMRI（实测） | 职引原型（`index.html :root`） | 用途 |
| --- | --- | --- | --- |
| 页面底色 | 米白纸感 `#F5F3EF` | `--paper:#F5F3EF` | hero、footer、工作台底 |
| 卡片底色 | 白 `#FFF` | `--card:#FFFFFF` | 内容卡片、聊天气泡 |
| 正文文字 | 近黑棕 `rgb(28,24,22)` | `--ink:#1C1816` | 标题与正文 |
| 次级文字 | 灰 `rgb(120,115,110)` | `--gray:#6E6A65` | 说明、meta |
| 弱化文字 | — | `--muted:#96918A` | 来源注、footnote |
| 强调蓝（主 CTA） | `rgb(55,138,221)` | `--blue:#378ADD` / 深 `--blueD:#1F6FBF` | 用户气泡、主按钮、当前步 |
| 强调绿（辅助） | `rgb(56,185,121)` | `--green:#38B979` / 深 `--greenD:#1E9E60` | 画像已沉淀、任务勾选 |
| 分类底色扩展 | 各分类淡背景卡 | blue/green/amber/red/purple Soft 系 + Line 系 | 画像分组、维度分区 |
| 智能体/角色色 | — | `--violet:#6C5BD8` + purpleSoft/Line | 智能体角色徽章 |

| 卡片圆角 | 14–18px（小卡 10–12px） | `--r:16px`；chip/mtag 8–12px | 卡片与标签 |
| 阴影 | 柔和投影 | `--shadow / --shadowLg` | 卡片浮起、toast |
| 字体栈 | 微软雅黑 / PingFang 类 | Microsoft YaHei / PingFang SC / Segoe UI | 全局 |

### 1.2 语言气质

- 沿用 mri 的**公式化价值主张**与英文微距 kicker：`15 维 / 1–4 套 / 1 份行动计划 / ≈5min` 作为首屏数字信任状；
- 中文口语化引导 + 术语克制：首屏主文案改为「不用填表，开口就能聊出一条职业路径」，强调「对话引导、不前置表单、有路径能执行」。

## 2. 视觉规范（设计令牌全表）

以下令牌定义可直接在原型 `index.html :root` 中查到，供开发对齐。

```css
--paper:#F5F3EF;  --card:#FFFFFF;
--ink:#1C1816;    --gray:#6E6A65;  --muted:#96918A;  --line:#E8E3DA;
--blue:#378ADD;   --blueD:#1F6FBF; --blueSoft:#EBF5FF; --blueLine:#C9E2FB;
--green:#38B979;  --greenD:#1E9E60;--greenSoft:#EAF9F2; --greenLine:#BDEBD6;
--amber:#B7791F;  --amberSoft:#FBF0CE; --amberLine:#EFDCA2;
--redSoft:#FFF0EE;--redLine:#F5CDCA;   --red:#C4503D;
--purpleSoft:#F2EDFF; --purpleLine:#D8CDF3; --violet:#6C5BD8;
--inkCard:#2A2723; /* toast 深底 */
--r:16px; --pill:999px;
--font:"Microsoft YaHei","PingFang SC",-apple-system,"Segoe UI",sans-serif;
```

### 2.1 颜色使用规则

| 色 | 语义 | 使用场景 |
| --- | --- | --- |
| 蓝 #378ADD | 主行动色 | 用户消息气泡、主按钮、当前阶段、维度图标、logo |
| 绿 #38B979 | 完成/成长 | 画像「已沉淀」、任务勾选✓、已完成阶段 |
| 琥珀 #B7791F | 注意/缓冲 | 风险提示、保底方案强调、阶段 tag |
| 红 #C4503D | 风险 | 维度结论「风险」组 accent（弱化使用） |
| 紫 #6C5BD8 | 智能体/角色 | 对话内「建档分析师 / 职业顾问 / 路径规划师」角色徽章 |

**Soft 色规则**：分类卡/维度组/画像项底色一律用 `-Soft` 淡底 + 对应 `-Line` 描边；文字落 `-D` 深一档保证对比度。禁止大面积高饱和底色。

### 2.2 文字层级

| 层级 | 规格 | 场景 |
| --- | --- | --- |
| H1 落地主标题 | 40–44px / 800 | hero「不用填表，开口就能聊出一条职业路径」 |
| H2 区块标题 | 26px | 输出能力/三步/工作台区头 |
| H3 卡片标题 | 16–19px | 方案名、维度名、报告卡标题 |
| 对话正文 | 14px / 1.7 | AI / 用户气泡文字 |
| 注释 | 11–12.5px / muted | 来源、meta、footnote |
| kicker | 10–11px / 字距 .14–.22em / 大写 | 微距标签 |

### 2.3 组件规范（沿用）

- **主按钮 `.btn-pri`**：蓝底白字、胶囊 999px，hover 转深蓝，带蓝投影；大按钮 `.btn-lg`。
- **次按钮 `.btn-ghost`**：透明底、灰字、`1px --line` 描边，hover 描边与文字转蓝。
- **信息芯片 `.pchip`**：画像字段 chip，paper 底 + line 描边，字段名 `<b>` 灰字。
- **进度条**：匹配度 / 画像覆盖度用圆角条，蓝→绿渐变。
- **toast**：深底白字胶囊，底部居中弹出，2.4s 自动消失。

### 4.1 对话建档（AI 分步提问 + 画像抽屉渐进填充）

```

│ 已读取你的个人资料与简历——当前画像为空。       │

   （选择后，右侧画像抽屉开始填充）

● 建档分析师（AI，携带 mtag「依据 · 帕森斯 · 了解自我」）
   先问一个缺口：你的学校、专业、年级和成绩排名是？
   [ 沈阳建筑大学 · 土木工程 · 大四 · 2027届 · GPA3.2 ]   ← 快捷回复
   （点击后追加用户气泡 + 下一问；右侧「学业」→ 已沉淀）
   …依次补全 技能 / 经历 / 目标 / 兴趣 / 就业偏好（共 6 问，一次一问）

● 画像总结（AI，mtag「帕森斯 · 人职匹配」）
   画像已沉淀（6/6）。下一步 15 维深度解析…
   [ 开始 15 维深度解析 → ] [ 先补充更多信息 ]
```

交互要点：
- **一次只问一个缺口**，替代「一张大表单」；答案以快捷回复呈现（演示环境），点击即回答并推进。
- 右侧画像抽屉每个维度带 `待采集 → 已沉淀` 状态 + 方法论小字，覆盖度进度条 0/6 → 6/6 实时刷新。
- 「上传简历」是加速通道：点击后走解析动画，最终**同样回填到同一个画像抽屉**，两条路径收敛为一份画像。

### 4.2 智能体解析 overlay `#veil`

固定全屏半透明遮罩 + 中央白卡：spinner → 角色徽章（建档分析师 / 职业顾问轮播）→ 单行 agent 文案 → 蓝绿渐变进度条。心智：**多智能体围绕同一份画像协作**，把黑盒等待翻译成过程可感。建档与 15 维解析共用本 overlay，仅文案不同。

## 6. 原型验证记录

浏览器自动化（Playwright，桌面 1440px + 移动端 390px 双视口）已对以下链路完成冒烟验证（全程控制台 0 报错）：
