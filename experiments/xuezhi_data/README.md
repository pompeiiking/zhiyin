# 学职平台核心数据源实验

目标站点：`https://xz.chsi.com.cn`。

当前实验读取无需登录的“专业洞察”和“职业探索”入口页，扫描公开接口候选，并从专业列表、职业列表各拉取最多 5 条样本完成规范化。它不会登录、提交表单、读取个性化推荐或测评，也不会绕过验证码和访问控制；原始页面和接口响应不落盘。

```powershell
python .\xuezhi_experiment.py --limit 5 --output .\output\sample.json
```

发现结果只是适配器开发输入，不等于已经取得自动采集授权。来源负责人仍需确认版权声明、访问条款、robots、允许字段、频率、保存期限和下架方式，之后才能把来源状态从 `pending_review` 改为 `enabled`。
