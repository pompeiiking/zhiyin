## 三、三项关键口径（实现时照此写，不再发散）

1. **轴 A 五段 + 单轨焦点**：全局单阶段，任务会话可带 `path_focus`（就业 / 考研 / 留学）；
   阶段推断"规则优先、LLM 兜底"，前台永远不让用户自选阶段。
2. **采集收尾**：关键字段集为 `职业兴趣 / 能力优势 / 价值观与职业锚 / 目标方向 /
   决策时间窗 / 现实约束`；覆盖率达到 80% 且整体置信度 ≥ 0.7 才结束，
   缺口 = 未覆盖或置信度 < 0.6 的关键字段，直接决定追问顺序。
3. **主动干预**：停滞 3 天无关键动作、同一条提醒冷却 48h、任意 7 天窗口最多 2 次；
   有动作的定义是作答 / 认领差距 / 选择方案 / 勾任务 / 更新画像，纯浏览不算。
