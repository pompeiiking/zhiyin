## 一、状态填写规则

| 状态 | 使用条件 |
| --- | --- |
| 未开始 | 尚未修改代码或只完成阅读 |
| 进行中 | 已开始实现，但尚未满足完成定义 |
| 阻塞 | 因缺少业务口径、契约、权限、环境或上游交付而无法继续 |

| 待联调 | 已装配并通过本模块测试，等待上下游或 E2E |
| 已完成 | 实现、测试、装配、联调及本阶段验收全部完成 |
| 移出本期 | 经负责人确认不属于当前里程碑，并记录决策编号 |

状态更新必须附至少一种证据：提交/PR、测试结果、装配报告、联调记录、数据样例或评审决议。

## 十三、更新约定

1. 开始任务时把状态改为“进行中”并填写开始日期。
2. 出现阻塞当天登记，不在周报时补写。
3. 代码完成但未装配时只能标“待装配”，不能标“已完成”。
4. 通过单元测试但未完成 E2E 时标“待联调”。
5. 只有实现、测试、装配、联调和阶段验收均完成后才标“已完成”。
6. 每波结束更新总体完成度、测试记录、装配快照和遗留风险。
7. 工作范围变化必须记录决策编号；不得直接删除未完成任务来提高完成度。
