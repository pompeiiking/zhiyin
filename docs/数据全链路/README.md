# 职引 · 数据全链路文档索引

本目录集中维护数据能力全链路负责人的计划、开发规范、架构设计、平台接入、实施验收和审计记录。分类仅调整文档落位，不改变各文档原有业务口径。

## 一、推荐阅读顺序

1. [智能体交接文档](00-索引与变更/职引-数据全链路智能体交接文档-2026-09-19.md)：换智能体时先确认当前分支、运行状态、完成项和下一步。
2. [工作清单](01-计划与规范/职引-数据能力全链路工作清单.md)：确认当前期次、范围和交付物。
3. [开发须知](01-计划与规范/职引-数据能力全链路开发须知.md)：确认文件落位、依赖边界和验收方式。
4. 对应专题设计：Redis、采集、RAG 或 PAMI 接入。
5. [完成情况记录](04-实施与验收/职引-数据能力全链路完成情况记录.md)：查看实现、测试、阻塞和联调证据。
6. [修改日志](00-索引与变更/职引-数据全链路修改日志.md)：查看文档与工程的重要变更时间线。

## 三、维护规则

- 工作范围或排期变化更新 `01-计划与规范`，不在完成记录中反向创造计划。
- 技术方案更新 `02-架构与设计`；外部平台契约和联调事实更新 `03-平台接入`。
- 只有带测试、提交、装配报告或联调记录的事项才能在 `04-实施与验收` 标记为完成。
- 审计文档保留当时快照；整改后的事实以追加说明记录，不静默改写历史结论。
- 重要目录调整、方案变化、完成状态变化统一追加到修改日志。
- API Key、密码、数据库连接串等秘密不得写入任何文档或提交记录。
