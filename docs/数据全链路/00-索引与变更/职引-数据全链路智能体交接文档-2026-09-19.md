## 七、关键架构边界

- `zhiyin-kernel`：共享数据形状与枚举。
- `zhiyin-data-sdk`：Repository、Gateway、Transaction 抽象，不放实现。
- `zhiyin-infrastructure`：MySQL、Redis、MinIO、pgvector、PAMI 等适配器和纯数据 Worker。
- `zhiyin-business`：职引业务规则和 Service。
- `zhiyin-orchestration`：Agent、Workflow、EventBus、Schedule、State、Notify 通用原语。
- `zhiyin-boot`：唯一装配层。
- API 层不得直接依赖 Data SDK。
- 不得重新引入已删除的 `KnowledgeGateway` / `KnowledgeHit` 重复链路。
- `VectorGateway` 只作为 Search 实现内部的向量存储原语，业务层不得直接调用。
- 不要手改 `contracts/openapi.json` 和 `zhiyin-web/src/api/types.ts`，必须从源 DTO 重新生成。
- 修改冻结 Port、共享模型、公开 DTO、事件载荷、数据库语义或共享写点前，按 `AGENTS.md` 先说明影响并取得确认。
