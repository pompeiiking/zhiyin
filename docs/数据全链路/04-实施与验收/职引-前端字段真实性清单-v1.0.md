## 一、四类口径

| 判定 | 含义 | 能否当业务事实用 |
| --- | --- | --- |
| **真实** | 值由后端接口下发，且内容是真实业务数据 | 可以 |
| **接口真实 / 内容 Mock** | HTTP、MySQL/Redis/MinIO 链路真实，但内容由 `LocalModelGateway` 占位串产出 | **不可以** |
| **前端演示** | 前端硬编码，与后端无关；后端不返回该字段或返回 `null` 时仍照常渲染 | **不可以** |
| **前端兜底** | 接口失败时回退到演示数据（`preview=true`） | **不可以** |

核心区分：**「接口 200」不等于「内容是事实」。** 当前页面上多数可见字段属于第二类。

占位串单点定义在 `zhiyin-infrastructure/zhiyin_infrastructure/local/llm.py:28`：

```text
_PLACEHOLDER_TEXT = "（第一期 Mock 产出，未接真实模型）"
```

它已经流到用户可见位置（对话正文、理论引用、行为引导、画像字段、依赖图），所以本文的标注不是锦上添花，而是防止演示被误读的必要手段。

## 十一、高风险项（按「会误导评审」的程度排序）

1. **轴 A 阶段会被当成系统推断结果。** 接口 `axis_a_stage` 实测为 `null`，前端显示硬编码「冲刺行动期」，旁边还有「不是这样，纠正」按钮 —— 看起来像系统推断出错，实际是演示值（`WorkspacePage.vue:142`、`workspace.ts:15`）。轴 A 依据 `axisABasis` 更严重：DTO 里根本没有该字段，永远是硬编码的「画像覆盖度 67%、整体置信度 78%」。
2. **工作台用硬编码覆盖后端已下发的功能块。** `blocks`（FR-WB-007，含成就徽章键等）后端已返回，页面却渲染硬编码日历与 6 枚成就徽章（`WorkspacePage.vue:85-100`）。
3. **`MockBadge` 不会随真实数据消失。** 6 处调用全部写死 `source="demo"`；报告页即使拿到了真实 `report_id` 仍标注「演示数据」。反向也成立：**没有任何机制能标注「这段是 Mock 模型产出」** —— 对话正文、画像字段里的占位串目前只能靠字符串匹配识别（MOCK-1）。
4. **核心对话页整屏无标注。** `ConversationPage.vue` 及其三个子组件都不含 `MockBadge`；在没发生过真实对话时，整屏演示内容与真实产出外观完全一致。
5. **同一份「15 维结论」有两套来源。** 前端用 `DEMO_SCORES`（`agents.ts:98-114`），后端 `report_panel` / 报告 sections 用 Mock 模型产出。工作台、报告页、智能体页都读前者，所以**前端展示的匹配度与后端报告正文可能互相矛盾**。
6. **前端硬编码业务阈值。** `composables/index.ts:30-32` 把关键字段 6、覆盖率 0.8、置信度 0.7 写成前端常量，与「阈值只在 `policy_params.json`、不得硬编码」的口径冲突（该文件注释已自认是演示期落地值）。
7. **画像口径存在第三处实现。** 已知 OPEN-6 记录了 `policies/profile.py` 与 `mappers.py` 两处；前端 `useProfileCoverage` 又按自己的常量算了一遍「覆盖率 × 6」。
8. **死数据与死契约。** `workspace.agents`（state）无读取方；`trust_blocks` / `banners` / `faqs` 无渲染方。它们会让「契约已接通」的结论偏乐观。

## 十二、处理建议

## 十三、复核脚本

只发 GET、只读响应，不写任何数据；可直接在仓库根目录执行（后端需在 `127.0.0.1:8000`）：

```python
import json, urllib.request

def get(path):
    with urllib.request.urlopen("http://127.0.0.1:8000/api/v1" + path, timeout=10) as r:
        return json.loads(r.read().decode("utf-8"))

for path in ["/app/bootstrap", "/app/sessions", "/app/workspace", "/app/report/full-text"]:
    body = get(path)
    data = body.get("data")
    print(path, "code=", body.get("code"),
          "keys=", sorted(data.keys()) if isinstance(data, dict) else type(data).__name__)
```
