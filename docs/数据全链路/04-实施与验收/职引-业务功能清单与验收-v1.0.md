## 二、主链路实测（用户点名：「完整对话 → 生成报告」）

**探针**：实机探针脚本（临时产物，已清理）；**输出**：2026-09-19 实跑，`loop.py` ① 交接修复已进镜像。

| 步骤 | 端点 / 动作 | 实测结果 |
| --- | --- | --- |
| 0 | `GET /healthz` | `200 status=degraded demo=['search']`（检索内容仍是演示语料，见 §六 MOCK-3） |
| 1 | `GET /app/bootstrap` | `200`，入口 7 条（`confused / verify_direction / undecided / how_to_act / stuck / review_due / free_chat`） |
| 2 | `POST /app/task/enter`（confused） | `200 task=tsk_f7895926664d stage=collect` |
| 3 | `POST /app/conversation/message` 第 1 轮 | `200`，`stage=collect`，`lead=职业顾问`，`guide.kind=question`（非空），并返回 **`disclosure`（换主理告知）**：`profile_analyst → career_advisor`，理由「画像已达解析门槛」 |
| 4 | 第 2 轮 | **`>>> 第 2 轮离开 ① 采集，进入 diagnose`** —— ① 采集**自动交接**（本轮修复点，见 §七） |
| 5 | `GET /app/report/full-text`（进入前后对比） | `version 16 → 19`，`len 11529 → 11995`，`sections` **8 段**：`verdict / swot / dimension-1 / dimension-2 / dimension-3 / directions / action / profile` |
| 6 | `GET /app/workspace` | `200 profile=1.0 report=diagnose/v19 plan=decide/v28 axis_a=None` |
| 7 | `GET /app/conversation/history` | `200 messages=48 stage=diagnose stage_label=② 诊断匹配 cards=5` |
| 8 | `POST /app/task/enter`（stuck）→ 消息 | `200 stage=review`，`lead=路径规划师`，`guide.kind=task`（非空），返回 `disclosure`：`companion_coach → path_planner`，理由「⑤ 复盘判定需要再入环」 |

**结论**：
- ✅ **「完整对话 → 生成报告」真实可跑通**：报告正文落库、版本递增（16→19）、8 段结构非空、画像覆盖度 1.0、工作台读到诊断/计划版本 —— 满足 FR-ORCH-004（版本 +1、不整篇重生成）与 FR-ORCH-005（跨会话持久化）。
- ✅ **对话 → 报告 → 工作台 → 历史会话四条读链闭合**，且换主理 `Disclosure` 真实下发（FR-ORCH-003 已实现）。
- ⚠️ 但「对话 → 报告」**之后的写链本轮已补**：报告里的差距清单**可认领**（`POST /app/assets/gap-claims`）、行动计划的**任务可勾选**（`POST /app/tasks/done`），勾选/认领/选方案/复盘均写行为日志（B-1 + B-2 已修，详见 §七）；**剩余断点是「计划→干预」的主动触发**（B-3 未修）。

> **B-1/B-2 实机复跑（2026-09-20，同一探针）**：日历节点写入后 `GET /app/workspace` 可回读（`calendar_nodes` 0→1）；一轮真实对话使报告 `sections` **8 段 → 9 段**（新增 `gaps` 区块，含 3 条真实差距明细）；三连写（认领差距 → 选定方案 → 勾选任务）每步复读报告全文均正确；⑤ 行为记录数 **61 → 64**（三次真实动作各写一条）；工作台成就出现 `first_task_done`。**每一断言均回读后端业务数据，不以 200 作为成功。**

**五环节实测耗时（前序同环境）**：① 200 / ② 200（Report v4）/ ③ 84.0s 200（`direction_plan` v15）/ ④ 119.4s 200（`action_plan` v1，首任务 `task_install_python`）/ ⑤ 18.4s 200。
