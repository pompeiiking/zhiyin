## 一、标记定义

| 标记 | 含义 | 是否可计入真实能力完成 |
| --- | --- | --- |
| REAL | 已接真实实现并完成运行验证 | 可以 |
| MOCK | 返回结构合法的模拟结果，主要用于链路联调 | 不可以 |
| DEMO | 演示或种子数据，不是生产采集数据 | 不可以 |
| SKELETON | 契约和落位存在，但实现仅为骨架 | 不可以 |
| NOT_WIRED | 实现未装配到运行链路 | 不可以 |
| CONTRACT-MOCK | 通过 MockTransport 验证请求/响应契约，未访问真实平台 | 只能计入契约测试，不可计入真实联调 |

## 三、Mock 内容流向

Schema Mock 产出会进入以下用户可见或可读取位置：

| 位置 | 当前表现 | 是否已有可靠标记 |
| --- | --- | --- |
| 对话消息 | `messages[].text` 可能包含 Mock 占位文案 | 否，DTO 无机器可判来源字段 |
| 主理/理论展示 | `badge.theory_refs` 中可能出现 Mock 合成值 | 否 |
| 行为引导 | `guide` 文案与选项可能由 Mock 合成 | 否 |
| 用户画像 | `ProfileField.value` 可能落入 Mock 合成值 | 否 |
| 工作台依赖图 | `from_asset`、`via_profile_keys` 可能出现 Mock 合成值 | 否 |
| 报告、方向方案、行动计划 | 正文会真实落库，但正文来源仍是 Mock 模型 | 否；“真实落库”不等于“真实模型生成” |

## 四、前端标记现状

`zhiyin-web/src/components/common/MockBadge.vue` 已实现 `mock`、`demo`、`real` 三种来源判断：

- `source="mock"`：展示 `mock.source_notice`。
- `source="demo"`：展示 `demo.data_notice`。
- `source="real"` 或未传：不展示徽标。

但当前后端对话及资产 DTO 没有 `source`、`is_mock` 或 `content_source` 字段，因此前端无法可靠地给五环节模型产出传入 `source="mock"`。对应测试
`tests/e2e/test_phase1_open_items.py::test_mock_content_carries_machine_readable_source`
保持 `xfail`，这属于显式未闭合项，不得用字符串匹配冒充已完成。

首页信任区的示例内容由 `TrustSection.vue` 在 Preview 状态显式传入 `source="demo"`，该处 DEMO 标记可正常展示。
