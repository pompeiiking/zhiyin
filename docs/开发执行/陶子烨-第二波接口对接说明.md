# 陶子烨 · 第二波接口对接说明

## 一、对接结论

本轮不改变公开 HTTP、OpenAPI、Kernel、业务 Port 或五类既有策略 ABC。新增的 Axis A Policy 是业务层内部策略；`DefaultOrchestrator` 新增的构造依赖已在 Boot 最小装配中同步。

## 二、冻结接口

| 能力 | 调用接口 | 本轮约束 |
| --- | --- | --- |
| 意图识别 | `IntentPolicy.classify(message, blackboard)` | message 为用户原文 |
| 环节判定 | `StagePolicy.decide(blackboard, intent, message)` | message 为用户原文；策略不保存澄清次数 |
| Axis A | `AxisAInferencePolicy.infer(blackboard, path_focus)` | 确定时返回阶段，不确定返回空 |
| 主理选择 | `LeadPolicy.select(blackboard, axis_a, stage, intent)` | 四个输入必须全部保留 |
| 交接告知 | `HandoffPolicy.decide(...)` | 换主理时 disclosure 必须非空 |
| 影响面 | `ImpactPolicy.select_affected(...)` | 只选择，不执行重算 |
| 主动干预 | `InterventionPolicy.should_intervene(...)` | 只判断，不发送通知 |

`Orchestrator` 的七个公开方法及 TurnRequest、TurnResult、StageDecision、LeadDecision、HandoffDecision 均保持原签名。

## 三、资产转换契约

| 业务产出 | 持久化形状 | 映射口径 |
| --- | --- | --- |
| DiagnoseOutput | Report | verdict、swot、dimensions 原样；sources 来自知识命中与事实证据；methodologies 来自已验证理论引用 |
| DecideOutput.plans | DirectionPlan | option_id→id；关联最新 report；字符串 gap→PlanGap.requirement，其他字段留空 |
| ActOutput | ActionPlan | phases 原样；只关联已选方向；全部提醒已同步时 reminders_synced=true |

三类正文必须分别通过 `AssetService.save_report`、`save_direction_plans`、`save_action_plan` 写入；不得再单独调用 `save_version` 制造“有版本、无正文”。

## 四、知识引用契约

KnowledgeGateway 只在 DIAGNOSE、DECIDE 环节调用：

```text
用户原文 + 当前主理的动态理论卡
  → KnowledgeGateway.search(namespace="theory")
  → AgentRequest.prompt_vars.knowledge_hits
  → TheoryRef(theory_id=doc_id, name=title, stage=当前环节)
```

- 模型返回但不在本轮命中集合中的引用不得展示。
- 无命中时返回空引用，不以 Mock 占位串冒充来源。
- Report.sources 优先写 `metadata.source_url`，其次写 `metadata.source`，并去重。
