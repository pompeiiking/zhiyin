## 1. 文档定位

本套文档从当前仓库反向梳理 Wanwu 平台架构，覆盖平台能力、服务边界、前端、智能体与工作流、模型与 RAG、数据、通信、安全、部署、可靠性和二次开发。文档既描述 Git 基线，也把当前工作区中的正式功能改动纳入架构。

> 本套文档所称 Wanwu，即职引总架构中的 pami（联通元景葩米 Lite / Wanwu）平台；文档名、代码路径和进程名仍沿用 Wanwu。

## 2. 状态标识

| 标识 | 含义 |
|---|---|
| `【已提交】` | 能力或实现存在于当前 Git `HEAD` |
| `【未提交】` | 当前工作区新增的能力或文件 |
| `【混合】` | 基线能力仍存在，但工作区已改变其行为或边界 |
| `【外部依赖】` | 能力来自独立镜像、第三方平台或外部服务 |
| `【运行验证】` | 结论有接口测试或本机部署记录支撑 |
| `【静态推断】` | 结论来自代码或配置，未取得当前运行验证 |

“未提交”不等于无效；它表示尚未进入 Git 历史，回滚、迁移和协作时必须单独保护。

## 5. 证据规则

结论优先级为：源码/Proto/路由/Compose → 配置/Nginx/构建脚本 → 官方说明/Swagger → 测试报告/部署日志 → 静态推断。运行记录只能证明其实际覆盖的版本与场景。

## 6. 核心术语

| 术语 | 含义 |
|---|---|
| BFF | Browser/Backend For Frontend；统一承接浏览器和开放接口并聚合内部服务 |
| IAM | 身份、组织、用户、角色和菜单权限管理 |
| RAG | 检索增强生成；先从知识库召回内容，再交给模型生成答案 |
| MCP | Model Context Protocol；模型/智能体连接工具服务的标准协议 |
| AgentScope | 工作流定义、编排和执行引擎，作为独立 Python 镜像运行 |
| Action | Python Agent 侧可被智能体调用的工具动作 |
| SSE | Server-Sent Events；用于智能体与 RAG 的增量输出 |
| 资源范围 | 资源所属用户、组织以及可见/可用边界 |
| 成员授权 | 创建者将指定资源使用权授予同组织成员的未提交能力 |

## 7. 安全说明

文档只记录配置项的职责，不记录 `.env` 中的实际值。示例中的地址为拓扑名称或占位域名；密钥、密码和 Token 不进入架构文档。
